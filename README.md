# AppFlow Profiler

> **Status:** 🚧 in development

AppFlow Profiler is an enterprise-grade network topology and observability dashboard for SRE and
platform teams. It discovers OS-level process connections, aggregates them into a live service
graph, streams incremental updates over WebSockets to a high-performance React Flow canvas, and
uses an LLM-powered Optimization Advisor to explain bottlenecks such as connection-pool
saturation, retry amplification and hot datastores. A deterministic Simulation Mode powers the
public demo.

See [`docs/MASTER_PLAN.md`](docs/MASTER_PLAN.md) for the full architecture.
